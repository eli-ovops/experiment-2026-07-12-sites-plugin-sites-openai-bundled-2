# ClaimFlow 首页降噪重构审查报告

## Short Summary

首页已从约 20 个重复展开模块压缩为 8 个核心叙事部分，以 Riverside Medical Center 的 East Corridor Conduit Reroute 单一案例贯穿现场证据、合同期限、人工审核和最终证据包。Hero 改为真实感施工现场与五条证据叠层；成熟 SaaS 定价改为 30-Day Recovery Pilot；CTA 不再依赖 mailto，新增明确标注的本地 Demo 申请表。

## 能力状态

### AVAILABLE IN PILOT

- 授权文件导入
- 变更事件辅助审查
- 合同通知期限提取
- Evidence gap review
- 单项目 review-ready evidence package

### ASSISTED WORKFLOW

- 事件判断、合同核对、成本支持和证据包生成均需人工参与。
- PM 或获授权商业负责人拥有最终审核、编辑、导出和提交决定权。

### PLANNED / NOT CLAIMED AS AVAILABLE

- Procore、Autodesk、WhatsApp、WeChat 等直接 API 集成未在首页宣称可用。
- CRM 提交、正式数据存储、生产安全控制和自动化客户提交均未实现或未宣称。

## 响应式验收

- Desktop 1440×900：通过；双栏 Hero、横向工作流和 Evidence Package 保持完整。
- Tablet 768×1024：通过；布局转为单列/双列混合，无横向溢出。
- Mobile 390×844：通过；首屏突出主 CTA，固定 Pilot CTA 生效，无横向溢出。
- Mobile 320×700：通过；标题断行可读，页面宽度与视口一致，无横向溢出。
- PDF 预览在移动端使用局部横向滑动区域，页面本身不溢出。

## 无障碍检查

- 单一 `h1`；分段使用 `h2` / `h3`。
- 两张现场图片均有有效 alt；Hero 图片 eager，非首屏图片 lazy。
- FAQ 使用语义化 button 和 `aria-expanded`。
- 表单所有字段均有 label；错误使用 `role=alert`，成功使用 `role=status`。
- 键盘焦点样式明确；关键点击目标不低于 44px。
- 状态文字不只依靠颜色表达。
- 支持 `prefers-reduced-motion`。

## 已知问题

- Pilot 表单是本地 Demo，不会传输或保存数据；正式 CRM/API 尚未接入。
- 现场照片为生成的说明性视觉资产，不是真实客户证据，页面已明确标注 Illustrative。
- Evidence Package 是前端视觉预览，不是可下载 PDF。
- 直接 API 集成、生产安全控制、数据保留条款仍需正式产品和法务确认。
- Vinext 的 `next/image` 在当前客户端开发运行时触发 Hook 错误，因此使用预压缩 135KB WebP 直接加载，并记录兼容性注释。

## 下一步建议

1. 由产品、商业索赔顾问和试点客户共同确认案例术语、合同逻辑和 Pilot 输入/输出。
2. 获得可授权使用的真实脱敏邮件、日报、T&M Ticket 与最终 PDF 样例后，替换说明性文档视觉。
3. 明确 CRM/API、数据处理、保留、安全和隐私方案后，再将 Demo 表单接入外部系统。
4. 用户验收通过后，由独立发布线程决定是否提交、推送或部署。

## 风险等级

中等。主要风险不是前端稳定性，而是当前图片和案例仍为说明性内容、Pilot 表单未接后端、真实产品能力与数据治理尚需确认。发布前必须由业务 Owner 审核真实性和法律边界。
